# IngotKit

Open-source AI SaaS starter for flat-rate Hostinger hosting: auth, credits, payments and
AI image and video generation on Next.js and MySQL.

**Work in progress.** This npm package is reserved for the project's future command-line
setup tool. There is nothing to install yet.
